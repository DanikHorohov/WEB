# Final Project — HTML / SCSS / JavaScript / Vite

Цей проєкт — фінальна робота, створена з використанням **HTML**, **SCSS**, **JavaScript** та збірника **Vite**.  
Він містить адаптивну головну сторінку, галерею з зображеннями, секцію постів, форму підписки та інші елементи сучасного UI.

---

## 🚀 Функціонал 🚀

### Головний екран (Hero Section)
- Великий заголовок
- Кнопки CTA (“Learn more”, “Get started”)
- Фонове зображення з preload для прискорення завантаження

### Меню сайту
- Адаптивне бургер-меню
- Навігаційна панель

### Галерея
- 9 зображень різного формату (різні сітки: великі ряди, колонки, адаптивні блоки)
- Відкриття фото у новій вкладці
- Кнопка “View all skills”

### Секція “Ready?”
- Заголовок і описові параграфи
- Ілюстративне зображення

### Форма підписки
- Поля: імʼя, email
- Валідація через HTML5

### Секція постів
- 6 постів у різних форматах (звичайні та широкі)
- Зображення + заголовок + текст
- Кнопка “View all posts”

### Footer
- Короткий слоган
